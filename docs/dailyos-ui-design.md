# dailyOS UI Design

## 1. Product Direction

dailyOS는 일정, 할 일, 활동, 사진, 건강, 장소, 소비 데이터를 한 화면 흐름 안에서 연결하는 개인 Life Database OS다. UI는 한국어를 기본으로 하며, PC 브라우저에서는 좌측 사이드바와 대시보드형 카드 레이아웃을 사용하고 모바일에서는 하단 탭과 세로 카드 레이아웃을 사용한다.

핵심 원칙:

- 오늘 화면은 하루 운영 대시보드로 설계한다.
- 일정과 할 일은 데이터 구조와 UI 표현을 명확히 분리한다.
- 캘린더는 모든 날짜 기반 항목을 한 번에 조망하는 통합 뷰다.
- 입력 화면은 빠른 기록과 상세 편집을 모두 지원한다.
- AI 질문은 기록을 검색하고 해석하는 보조 계층으로 제공한다.

## 2. Visual Language

첨부 레퍼런스처럼 밝고 조용한 개인 OS 느낌을 사용한다.

- 배경: `#F5F6FB`
- 표면: `#FFFFFF`
- 사이드바: `#EEF2FF`
- 기본 텍스트: `#111827`
- 보조 텍스트: `#6B7280`
- 경계선: `#DDE3F0`
- 그림자: 낮고 부드러운 카드 그림자
- 모서리: 카드 `16px`, 내부 아이템 `12px`, 버튼/입력 `10px`

유형별 색상:

- 일정: 보라 `#7C3AED`
- 할 일: 초록 `#10B981`
- 운동/건강: 핑크 `#F43F5E`
- 몸무게: 파랑 `#2563EB`
- 취업: 주황 `#F59E0B`
- 설정/시스템: 회색 `#64748B`

## 3. App Shell

### Desktop

좌측 고정 사이드바와 우측 콘텐츠 영역으로 구성한다.

사이드바:

- 로고: dailyOS / Personal OS
- 사용자 프로필 요약
- 메뉴
  - 오늘
  - 캘린더
  - 시간관리
    - 일정
    - 할 일
  - 건강
    - 운동
    - 몸무게
  - 취업
    - 자격증
    - 지원 기업
    - 지원 예정 기업
  - 설정

콘텐츠:

- 상단 헤더: 화면 제목, 날짜, 주요 액션 버튼
- 본문: 화면별 카드/테이블/폼

### Mobile

모바일에서는 좌측 사이드바를 숨기고 하단 탭을 사용한다.

하단 탭:

- 오늘
- 캘린더
- 시간관리
- 건강
- DB
  - 라이프 캘린더
  - 전체 검색
  - 사람
  - 장소
  - AI 질문
- 장소
- 설정

기존의 커리어 중심 IA 문서는 현재 구현 기준과 다르다. 실제 제품 기준 내비게이션은 오늘, 기록, DB, 장소, 설정 축을 따른다.

설정은 상단 프로필 또는 더보기 메뉴에서 접근한다. 하위 메뉴는 각 섹션 상단의 세그먼트 탭으로 전환한다.

## 5. Today Dashboard

오늘 화면은 앱의 첫 화면이다. 사용자가 오늘 해야 할 일, 일정, 건강 기록, 취업 일정을 빠르게 파악하도록 설계한다.

### Desktop Layout

상단:

- 인사말: `좋은 아침입니다, 사용자님.`
- 오늘 날짜: `2026년 5월 12일 화요일`
- 빠른 추가 버튼: 일정, 할 일, 운동, 몸무게, 지원 일정

본문 2열 그리드:

- 좌측 넓은 영역
  - 오늘 일정 요약
  - 오늘 할 일 요약
- 우측 좁은 영역
  - 건강 요약
  - 임박한 취업 이벤트

하단:

- 최근 몸무게 추이 미니 그래프
- 이번 주 진행률 요약

### Cards

오늘 일정 요약:

- 시간순 카드 목록
- 제목, 시간, 장소, 카테고리
- 온라인 일정은 화상 아이콘 표시
- 취소된 일정은 흐리게 표시

오늘 할 일 요약:

- 완료율 프로그레스 바
- 우선순위 배지
- 상태별 체크 UI
- `할 일`, `진행 중`, `완료` 상태 구분

건강 요약:

- 최근 몸무게
- 골격근량
- 체지방률
- 오늘 운동 기록 또는 운동 계획

임박한 이벤트:

- 지원 마감
- 시험
- 면접
- 결과 발표
- 자격증 만료
- D-day 배지 표시

## 6. Calendar

캘린더는 월간 뷰를 기본으로 한다.

### Desktop

- 좌측: 월간 캘린더
- 우측: 선택한 날짜 상세 리스트
- 상단: 월 이동, 오늘 이동, 유형 필터

날짜 셀 표시:

- 일정: 보라 점/바
- 할 일: 초록 점/바
- 운동: 핑크 점/바
- 몸무게: 파랑 점/바
- 취업: 주황 점/바

상세 리스트:

- 선택 날짜 제목
- 유형별 섹션
- 항목 클릭 시 상세 드로어 열림

### Mobile

- 월간 캘린더를 상단에 배치
- 날짜 선택 시 하단에 상세 리스트 표시
- 유형 필터는 가로 스크롤 칩 사용

## 7. Time Management

시간관리는 `일정`과 `할 일`을 분리된 탭으로 제공한다.

### 일정

목록 화면:

- 일/주/목록 보기 전환
- 시간순 정렬
- 카테고리 필터
- 빠른 추가 버튼

상세/입력 필드:

- 제목
- 시작 시간
- 종료 시간
- 장소
- 카테고리
- 메모

일정 카드:

- 시간
- 제목
- 장소
- 카테고리 색상
- 메모 존재 여부

### 할 일

목록 화면:

- 상태별 칸반: 할 일, 진행 중, 완료
- 또는 리스트 뷰 전환
- 우선순위/마감일 필터

상세/입력 필드:

- 제목
- 상태: 할 일, 진행 중, 완료
- 우선순위
- 예정일
- 마감일
- 메모

할 일 카드:

- 체크박스
- 제목
- 상태 배지
- 우선순위 배지
- 예정일/마감일

## 8. Health

건강은 운동 기록과 몸무게 추이로 나눈다.

### 운동

목록 화면:

- 날짜별 운동 기록
- 운동 종류 필터
- 컨디션 표시
- 최근 운동 루틴 복사 액션

운동 기록 필드:

- 운동 날짜
- 운동명
- 운동 종류
- 컨디션
- 메모
- 세트 기록

세트 기록 필드:

- 운동명
- 부위
- 세트 순서
- 중량
- 횟수
- 거리
- 시간
- 메모

UI:

- 운동 기록은 날짜별 카드로 표시
- 세트 기록은 테이블 형태
- 모바일에서는 세트별 접이식 카드 사용

### 몸무게

목록/그래프 화면:

- 최근 몸무게 카드
- 몸무게 추이 라인 그래프
- 골격근량 라인 그래프
- 체지방률 라인 그래프
- 기록 리스트

입력 필드:

- 날짜
- 몸무게
- 골격근량
- 체지방률
- 메모

골격근량과 체지방률은 선택 입력이며, 허리둘레 항목은 제공하지 않는다.

## 12. Responsive Rules

Desktop `>= 1024px`:

- 사이드바 고정
- 콘텐츠 최대 너비 제한 없이 넓게 사용
- 대시보드는 12컬럼 그리드
- 카드 2열 또는 3열

Tablet `768px - 1023px`:

- 사이드바 축소 또는 숨김
- 카드 2열
- 캘린더 상세는 하단 배치 가능

Mobile `< 768px`:

- 하단 탭 사용
- 카드 1열
- 테이블은 카드 리스트로 전환
- 폼은 전체 화면
- 중요한 액션은 FAB 또는 하단 고정 버튼 사용

## 13. PWA UX

- 설치 가능한 앱 이름: `dailyOS`
- 시작 URL: `/`
- 디스플레이 모드: `standalone`
- 테마 컬러: `#2563EB`
- 오프라인 기본 화면 제공
- 앱 아이콘은 파란색 dailyOS 워드마크 기반으로 제작

PWA 설치 후에도 브라우저 UI 없이 앱처럼 사용할 수 있도록 상단 헤더와 하단 탭의 높이를 안정적으로 유지한다.

## 14. Initial Screen Priority

1. AppShell
2. 오늘 대시보드
3. 캘린더 월간 뷰
4. 시간관리 일정/할 일
5. 건강 운동/몸무게
6. 취업 관리
7. 설정

첫 구현에서는 첨부 이미지와 같은 오늘 대시보드를 우선 제작한다. 이후 같은 디자인 토큰과 카드 패턴을 다른 메뉴로 확장한다.
